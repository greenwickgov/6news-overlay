# 6NEWS Headline Overlay

A self-contained GitHub Pages headline overlay. Solid dark blue, rounded corners, no gradients or external dependencies.

## Use

Open https://greenwickgov.github.io/6news-overlay/ to edit the label, headline and optional supporting line. Click **Apply headline**, then **Open overlay** for a transparent output without controls.

For OBS, use **Copy overlay link** and paste the URL into a 1920 × 1080 Browser Source. After editing, copy the new URL into OBS. The URL contains the chosen headline; browser tabs in the same profile also receive changes through local storage. There is no remote synchronization between devices or separate browser profiles.

**Hide overlay** toggles the graphic. Edits are saved on this browser when local storage is available. No accounts or backend are required.
